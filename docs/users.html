User Management (2 Pages)

Pages
PageFilePurpose
UsersPagepages/users/UsersPage.jsxList all users with search & filter
UserFormPagepages/users/UserFormPage.jsxCreate/Edit user form
Features
  • • User List - View all users with AG-Grid, search by name/email
  • • Create User - Add new user with username, email, password, role
  • • Edit User - Update user details, change password
  • • Delete User - Soft delete (is_active flag)
  • • Role Assignment - Assign role (admin, manager, user)
  • • Password Management - Secure password hashing with bcrypt
  • • Activity Tracking - Log user actions in activity_logs
