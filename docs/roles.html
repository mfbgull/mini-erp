Features
  • • Role List - View all roles with permission summary
  • • Create Role - Add new role with name & description
  • • Edit Role - Update role details
  • • Permission Management - Assign module permissions to roles
  • • Delete Role - Remove role (prevent if users assigned)
  • • Default Roles - Admin, Manager, User pre-configured
Built-in Roles
RolePermissionsDescription
Admin All permissions Full system access
Manager Sales, Inventory, Reports Operations management
User Basic CRUD Standard user access
Module Permissions
inventory sales purchases customers suppliers production reports settings users roles
API Endpoints (RolesController)
GET    /api/roles              - List all roles
GET    /api/roles/:id          - Get single role with permissions
POST   /api/roles              - Create role
PUT    /api/roles/:id          - Update role
DELETE /api/roles/:id          - Delete role
GET    /api/roles/:id/permissions - Get role permissions
PUT    /api/roles/:id/permissions - Update permissions
