# Plan: Compact Stat Cards on Items Page

## Problem
The ItemsPage has 8 stat cards (Total Items, Stock Value, Total Stock, Low Stock, Out of Stock, Categories, Raw Materials, Finished Goods). They use `auto-fit, minmax(160px, 1fr)`, so 8 items end up on 2 rows at ~900px total height each, pushing the table far down.

## Current Card Structure
```
Icon (32-36px)  |  Label (0.65rem)
                |  Value  (1rem)
                |  Subtitle (0.65rem)
```
Each card is ~60-70px tall. 8 cards × ~2 rows = ~150px stack, plus `StatsGrid` gap and `quick-actions` row below = significant vertical real estate.

## Options Considered

### Option A: Use existing `compact` class on `<StatsGrid>` (Minimal)
Add `className="compact"` to the existing `<StatsGrid>` in ItemsPage. The CSS already supports a 4-up layout at `repeat(4, 1fr)` with smaller padding, icons, fonts.
- **Pros:** JSX change only, 1 file touched, proven pattern (used in ProfitLossReport)
- **Cons:** Cuts 2-row → 2-row but narrower (still 2 rows of 4), ~30% height saving only

### Option B: `compact` + keep subtitles on first row only (Incremental)
Option A plus layering: make compact smaller ($8px$ padding) and only show subtitles on a hover reveal or keep them in compact but reduce font further.
- **Pros:** More space reduction without losing information
- **Cons:** More CSS rules needed, hover-reveal subtitles may conflict with mobile

### Option C: Stack to 1-row, shrink icon + remove icon band (Bold redesign)
Collapse stat cards to a 8-up row on desktop: remove icon background band, shrink icon inline with value:
```
Items  128    │  $45,000   │  1,230   │  ⚠ 3   │  🚫 0   │  Cats 4   │  RM 5   │  FG 6
```
- **Pros:** Maximum space saving — cards are inline, table rises significantly
- **Cons:** Different look from every other page in ERP, loses the stat-card component's identity, bigger refactor

### Option D: Compact + add `className="compact"` stat-grid with 2 subtitles merged (Balanced)
Apply `compact` class (Option A) and split cards into 2 `StatsGrid` rows: first row for the 4 key metrics (Total Items, Stock Value, Total Stock, Low Stock), second row for categories/type breakdown (Categories, Raw Materials, Finished Goods, Out of Stock). Each grid is 4-up compact.
- **Pros:** Keeps visual grouping (key metrics vs breakdown), still `compact` class, better cognitive flow
- **Cons:** Extra JSX nesting, adds another `<StatsGrid>` wrapper

## Recommended: Option A (Minimal + Targeted CSS)

Use the existing `compact` class on the `<StatsGrid>` in ItemsPage.jsx, plus two CSS refinements in `stat-card.css`:

**Change in `ItemsPage.jsx`** (line ~392):
```jsx
<StatsGrid className="compact">
```

**Changes in `stat-card.css`:**
1. Make `compact` use the same `repeat(auto-fit, minmax(130px, 1fr))` grid so it can break to fewer than 4 columns gracefully when the window shrinks (currently `repeat(4, 1fr)` forces exactly 4).
2. Reduce `compact` row height: smaller padding (`6px 8px` → `5px 8px`), smaller icon (28 → 24), smaller fonts (`0.55rem` labels → `0.55rem`, values `0.85rem`).
3. Hide subtitle by default in compact, show on hover to maximize the value-only row.

**Expected result:** Cards shrink from ~70px to ~44px each. 8 compact cards take ~90–100px vertical space total (vs ~150+ currently). The AG-Grid table jumps up ~50–60px closer to viewport. No change to mobile layout.

## Scope
| File | Changes |
|---|---|
| `client/src/pages/inventory/ItemsPage.jsx` | Add `className="compact"` to `<StatsGrid>`, remove subtitles from individual `<StatCard>` for compact view |
| `client/src/styles/components/stat-card.css` | Use `repeat(auto-fit, minmax(130px, 1fr))` in compact, trim padding/sizes, compact subtitle (show-on-hover) |

## No impact areas
- StatCard.tsx component — untouched
- Other pages using StatCard — untouched (they don't use `compact`)
- Mobile CSS already handles stat cards inline — no breakage
